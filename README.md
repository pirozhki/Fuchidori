# Fuchidori

画像に縁取り文字や影付き文字を配置できる、Windows 向けデスクトップアプリです。C++ / ATL / WTL で実装し、描画には Direct2D・DirectWrite、画像の読み書きには Windows Imaging Component (WIC) を使用しています。

## ダウンロード

最新の配布パッケージは [GitHub Releases](https://github.com/pirozhki/Fuchidori/releases) から入手できます。

## 主な機能

- PNG / JPEG / BMP / GIF / TIFF 画像の読み込みとドラッグ＆ドロップ
- フォント、サイズ、文字色、太字、斜体の設定
- 縦書き・横書きの切り替え
- 縁取り方式、縁取り色・幅、影のカスタマイズ
- 複数の文字オブジェクトを画像上に仮置きし、それぞれを個別に編集
- 文字オブジェクトの選択、ドラッグ移動、削除
- 選択中の文字の個別確定と、すべての文字の一括確定
- 右クリックメニューからの文字の確定・削除
- `Ctrl+Z` / `Ctrl+Y` による Undo / Redo
- 確定した文字を合成した PNG / JPEG / BMP 画像の保存

未確定の文字オブジェクトは編集用の枠とともに表示されます。黒い枠は未選択、赤い枠は選択中を示します。編集用の枠や未確定文字は保存画像に含まれません。

## 動作環境

- Windows 10 / Windows 11
- Visual Studio 2026（C++ によるデスクトップ開発、ATL）
- Windows SDK
- WTL 10.01

WTL は [WTL 公式サイト](https://wtl.sourceforge.io/) から入手してください。Direct2D、DirectWrite、WIC は Windows SDK のライブラリを使用します。

## ビルド方法

1. Visual Studio で「C++ によるデスクトップ開発」と ATL をインストールします。
2. WTL 10.01 を展開します。
3. 環境変数 `WTL_ROOT` を、`Include/atlapp.h` を含む WTL のルートフォルダーに設定します。たとえば `C:\WTL\Include\atlapp.h` が存在する場合、`WTL_ROOT` は `C:\WTL` です。
4. 必要に応じて、32×32 のアイコンを `src/Fuchidori.ico` に配置します。
5. `Fuchidori.sln` を Visual Studio で開き、`x64` の `Debug` または `Release` 構成でビルドします。

ランタイムライブラリは静的リンクを使用します（Debug: `/MTd`、Release: `/MT`）。

## 使い方

1. **ファイル → 画像を開く** を選択するか、画像ファイルをウィンドウへドラッグ＆ドロップします。
2. 文字設定ダイアログで文字列や書式を設定します。
3. オブジェクトが選択されていない状態で画像の空白部分をクリックすると、ダイアログの文字列とプロパティを使って新しいオブジェクトを作成します。新規オブジェクトは空の文字列で始めたい場合、ダイアログの文字列を空にしてください。
4. 文字オブジェクトをクリックすると選択され、ダイアログにそのオブジェクトのプロパティが表示されます。文字設定の変更は選択中のオブジェクトに反映されます。
5. オブジェクトの枠内をドラッグすると位置を変更できます。黒い枠は未選択、赤い枠は選択中です。
6. 選択中に画像の空白部分をクリックすると、まず選択解除されます。そのクリックでは新しいオブジェクトは作成されません。新規作成するには、選択解除後にもう一度空白部分をクリックします。
7. ダイアログの **この文字を確定** で選択中の文字を確定し、**すべて確定** で未確定オブジェクトを一括確定します。文字列が空のオブジェクトは確定時に削除されます。
8. 選択中のオブジェクトは、ダイアログの **削除** ボタン、`Delete` キー、または右クリックメニューから削除できます。右クリックメニューからはオブジェクトの確定も行えます。
9. **ファイル → 名前を付けて保存** で画像を保存します。未確定文字や編集用の枠は保存されません。

## キーボード操作

| キー | 操作 |
| --- | --- |
| `Ctrl+Z` | 元に戻す |
| `Ctrl+Y` | やり直し |
| `Delete` | 選択中の未確定文字オブジェクトを削除 |
| `Esc` | 選択解除 |

文字設定ダイアログのテキストボックスにフォーカスがある場合、`Ctrl+Z` はテキスト編集の取り消しを優先します。

## 設定と一時データ

文字設定はアプリ起動中のメモリで管理され、終了すると失われます。文字オブジェクトはそれぞれ独自の文字列・フォント・色・縁取りなどのプロパティを保持します。
