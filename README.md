# Fuchidori

画像に縁取り文字や影付き文字を配置できる、Windows 向けのデスクトップアプリです。

C++ / ATL / WTL で実装し、描画には Direct2D・DirectWrite、画像の読み書きには WIC を使用しています。

## スクリーンショット

![Fuchidori の画面](screenshots/fuchidori.png)

## 主な機能

- PNG / JPEG / BMP / GIF / TIFF 画像の読み込み（複数フレーム画像は先頭フレームを使用）
- エクスプローラーからウィンドウへのドラッグ＆ドロップによる画像読み込み
- 画像をクリックした位置への文字配置とリアルタイムプレビュー
- ダイアログを開いたまま画像をクリックして文字の配置位置を変更
- フォント、サイズ、文字色、太字、斜体の設定
- 横書きと縦書きの切り替え
- 縁取り方式（なし、標準、太い縁取り、影のみ、縁取り＋影）、縁取り色・幅、影の色の設定
- PNG / JPEG / BMP 形式での保存
- `Ctrl+Z` による元に戻す、`Ctrl+Y` によるやり直し
- フォントや描画スタイルなどの設定を INI ファイルに保存
- 入力中の文字列の一時記憶と、テキストボックスを空にするクリア機能

## 動作環境

- Windows 10 / Windows 11
- Visual Studio 2026（C++ によるデスクトップ開発、ATL）
- Windows SDK
- WTL 10.01

WTL は [WTL 公式サイト](https://wtl.sourceforge.io/) から入手してください。Direct2D、DirectWrite、WIC は Windows SDK のライブラリを使用します。

## ビルド方法

1. Visual Studio で「C++ によるデスクトップ開発」と ATL をインストールします。
2. WTL 10.01 を展開します。
3. 環境変数 `WTL_ROOT` を、`Include/atlapp.h` を含む WTL のルートフォルダーに設定します。たとえば `C:\WTL\Include\atlapp.h` が存在する場合、`WTL_ROOT` は `C:\WTL` です。
4. `Fuchidori.sln` を Visual Studio で開き、`x64` の `Debug` または `Release` 構成でビルドします。

ビルド成果物は `bin\Debug\Fuchidori.exe` または `bin\Release\Fuchidori.exe` に出力されます。

## 使い方

1. **ファイル → 画像を開く** を選択するか、画像ファイルをアプリのウィンドウへドラッグ＆ドロップします。
2. 文字を配置したい場所を画像上で左クリックします。
3. 文字入力ダイアログで文字、書式、縁取りなどを設定します。入力した文字は画像上にプレビューされます。
4. ダイアログを開いたまま画像上の別の場所をクリックすると、プレビュー位置が移動します。
5. **OK** で文字を確定し、**キャンセル** で今回の編集を破棄します。
6. **ファイル → 名前を付けて保存** から合成画像を保存します。

## キーボード操作

| キー | 操作 |
| --- | --- |
| `Ctrl+Z` | 元に戻す |
| `Ctrl+Y` | やり直し |

文字入力ダイアログのテキストボックスにフォーカスがある場合、`Ctrl+Z` はテキスト編集の取り消しを優先します。

## 設定と一時データ

フォントや色、縦書き・横書きなどの設定は、実行ファイルと同じフォルダーの `Fuchidori.ini` に保存されます。入力中の文字列はアプリのメモリにのみ保持され、INI ファイルには保存されません。アプリを終了すると、文字列の一時記憶は失われます。
